Methodology
How This Site Works

This site is fully automated. No human editors select, write, or review content before publication. No AI language models generate text. All content is either extracted from primary sources or computed by deterministic rules.

Data sources: Statistics Canada API, OpenParl (Hansard), LEGISinfo, Canada Gazette, CSE/CSIS/RCMP published releases, PRC Ministry of Foreign Affairs, Xinhua, People's Daily, Global Times, MOFCOM, General Administration of Customs, OpenAlex (academic partnerships), ASPI China Defence Universities Tracker, CFIA import database.

Translation: Chinese-language sources are translated using NLLB-200 (600M distilled), an open-source machine translation model by Meta AI running locally on this server. Translation quality is functional but imperfect. The original Chinese text is always available. No proprietary translation service is used.

Signal scoring: Every signal is scored 0-100 on four axes: Relevance (keyword match + entity match, 0-30), Magnitude (statistical deviation or event severity, 0-30), Novelty (deduplication against recent signals, 0-20), Source Weight (source credibility tier, 0-20). Thresholds: Significant ≥70, Notable ≥45, Routine ≥25, Noise <25. All keywords, weights, and thresholds are published in the source repository.

Escalation detection: Chinese diplomatic language is classified using keyword matching against a curated list of ~50 formulaic diplomatic phrases, tiered as elevated / firm / moderate / neutral. This is crude compared to expert analysis and misses context-dependent meaning. The keyword list is published.

Tension Index: Fully quantitative composite of 6 sub-indices (Trade Friction, Trade Volume, Diplomatic Frequency, Escalation Language, Parliamentary Intensity, Security Events). No editorial or AI input. Methodology and weights are published. Historical values are not retroactively adjusted.

Limitations: This site cannot conduct original reporting, file access-to-information requests, verify through human source networks, detect subtle diplomatic signals, or provide nuanced analysis of community impact. Machine translation may contain errors. Escalation detection is keyword-based and misses ~20-30% of what an expert would catch. Disruption detection has a higher false-positive rate than human assessment.

Operator: One person reviews system health weekly and performs quality audits monthly. The operator maintains keyword lists, active situations, and supply chain alt-source ratings. The operator does not write or edit signal content. Contact: operator@chinacompass.ca

Infrastructure: Hostinger KVM2 VPS (2 vCPU, 8 GB RAM, 100 GB NVMe). Ubuntu Linux, Python pipelines, SQLite, Hugo static site generator, NGINX. Total operating cost: <$20/month. Source code: published.

China Compass is an automated open-source intelligence monitor. It aggregates, structures, translates, and scores publicly available information about Canada-China relations. It does not generate text, conduct original reporting, or apply editorial judgment. Every data point links to its primary source. Every score is decomposable. The full methodology and source code are published.
